### Content Review Process

**Before Posting:**
1. Check against brand voice (no emojis, no hype)
2. Verify technical accuracy
3. Ensure on-chain verification where relevant
4. Check hashtag usage (max 2, from approved list)
5. Link to coffer.fun when relevant

**After Posting:**
1. Monitor replies
2. Respond to questions
3. Quote RT valuable replies
4. Update content queue based on feedback

### Red Lines (Never Do)

- Never promise returns
- Never use hype language ("moon", "gem", "100x")
- Never overuse emojis (max 1 per thread, for structure only)
- Never speculate on token prices
- Never FUD other projects
- Never post without technical basis
- Never link to off-chain resources as "proof" (use on-chain)
- Never tag irrelevant accounts for reach
- Never post engagement bait
- Never use clickbait headlines
